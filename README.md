# Sistema de Gerenciamento de Locadora de Carros

## O que faz?

Um programa que gerencia uma locadora de carros. Você pode cadastrar novos carros, listar, atualizar e deletar informações de veículos.

## Menu de Opções

- **0**: Sair do programa
- **1**: Cadastrar um novo carro
- **2**: Listar todos os carros
- **3**: Atualizar dados de um carro
- **4**: Excluir um carro

## Dados do Carro

Cada carro armazena:
- Nome/modelo
- Preço
- Placa
- ID (identificação)

## Limite

Pode armazenar até **100 carros** na locadora.
